# E-commerce Sales Analysis

Analyze revenue, product performance, city-wise sales and monthly trends.

## Tools
Python, Pandas, Matplotlib

## Run
```bash
pip install -r requirements.txt
python analysis.py
```

## Dataset
`data/ecommerce_sales.csv` contains 500 synthetic sample orders for practice.

## Key questions
- What is the total revenue?
- Which product and city generate the most revenue?
- How do sales change month by month?
- Which payment method is most common?
